# Public Asset Policy

The development build historically used a mixture of project art, third-party references and recognizable commercial-game characters. That is not an acceptable default for a public OSS repository.

## Included
- Source code, tests, protocol, schemas, deployment tooling and level logic.
- Assets with explicit permissive provenance, such as Kenney CC0 source metadata.

## Excluded
- Nintendo/Mario character art and audio with unclear redistribution rights.
- User-supplied/private-research character sheets whose original redistribution license was not verified.
- Other binary media without an explicit public license.

Public contributions should prefer original art or CC0/CC-BY/permissively licensed assets with source + license recorded in the same PR.
