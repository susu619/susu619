# Mario Web Multiplayer Port

这是对 `ByteTuxiaobei/Mario` 的网页与多人联机移植分支。上游版本固定为 `20eff8077f05690ebca00af42a906b82b37dde22`，许可证继续采用 GPL-3.0。

## 当前已完成

- 原项目 `1-1`、`1-2`、`1-3`、`1-4` 四个 `.mio` 关卡数据已直接写入 `shared/levels/`；
- 解析原项目的 `map_range`、`limit_time` 和关卡对象命令；
- 恢复原 C++ `Level::basic_block()` 动态生成的终点旗杆、终点平台和城堡结构；
- 服务器权威的固定 60 Hz 游戏模拟与 20 Hz 状态快照；
- 最多四人同房间同步，客户端只上传输入，不允许直接上传坐标；
- 马里奥移动、冲刺、长短跳、下蹲、受伤、死亡、复活和终点判定；
- 普通砖、隐藏砖、问号砖、碎砖和顶砖动画；
- 金币、蘑菇、火焰花、无敌星；
- 板栗、慢慢龟、踩龟变壳、踢壳和壳击杀；
- 火焰状态与服务器权威火球；
- Canvas 网页渲染、原项目精灵表加载、移动端触控、横屏和全屏；
- Node.js 同时提供网页静态文件、健康检查和 WebSocket 联机服务；
- 原关卡解析与权威模拟测试；
- Termux 一键安装、构建和启动脚本。

## 目录结构

- `shared/levels/`：已导入的原始 `.mio` 关卡；
- `shared/src/`：关卡解析、碰撞、角色、敌人、道具和状态序列化；
- `web/`：Canvas 浏览器客户端、输入与网络插值；
- `server/`：权威房间服务器与网页静态服务；
- `termux-start.sh`：Android Termux 启动脚本；
- `tools/import-upstream.sh`：需要完整上游 C++ 快照时使用的可复现导入工具。

## Termux 运行

在仓库目录执行：

```bash
bash termux-start.sh
```

脚本会自动安装 Node.js、安装依赖、构建网页并监听 `0.0.0.0:8080`。本机浏览器访问：

```text
http://127.0.0.1:8080
```

同一局域网中的其他设备使用手机局域网 IP 访问，例如：

```text
http://192.168.1.20:8080
```

## 普通 Linux、Windows 或 macOS

```bash
npm install
npm test
npm run build
npm start
```

开发模式：

```bash
npm run dev
```

默认联机端口是 `8080`，可通过环境变量修改：

```bash
HOST=0.0.0.0 PORT=9000 npm start
```

## 操作

- 左右移动：方向键或 `A/D`
- 下蹲：下方向键或 `S`
- 跳跃：`X` 或空格
- 冲刺：长按 `Z` 或左 Shift
- 火球：火焰状态下按 `C` 或左 Ctrl
- 手机：屏幕下方触控按钮
